允许“环境分贝计”录制音频吗？

分贝计需要麦克风权限来计算实时声压级 (RMS)。音频仅在内存中瞬时处理，不会被保存或上传。

shield

隐私权限透明白皮书

1. 无网络栈声明：该工具在 Manifest 中移除了 android.permission.INTERNET，从底层操作系统级别剥离网络数据出站能力。

2. 极简缓冲区：采用 AudioRecord.read(short[] audioData, int offset, int size)，大小仅为单个缓冲区块 (约 1024 采样点)，计算 RMS 均方根后变量立刻被 GC 回收。

3. 零落盘：无任何 FileOutputStream 或临时 WAV/AAC 写入逻辑，本地闪存无残留。
