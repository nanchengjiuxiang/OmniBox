# “万能工具箱” (OmniBox) 架构与产品技术规范文档

## 一、产品需求文档 (PRD) 摘要与设计原则
- **定位**：纯本地离线优先、隐私友好、零滥用权限的现代 Android 极简工具箱。
- **核心体验**：秒开、无启动页广告、遵循 Material You (M3 Dynamic Color) 规范、自适应浅/深色模式。
- **设计哲学**：
  - 工具自治：每个工具模块自包含，支持深链与独立生命周期管理。
  - 渐进式权限：不启动不索权，用前教育，拒绝后优雅降级。
  - 健壮性：严格规避 OOM，传感器无硬件回退，全量离线算法无网络交互。

## 四、工具动态注册机制 (Tool Registry)
无需在首页硬编码入口，通过轻量注册中心实现插拔式设计：

```kotlin
// :core:model
enum class ToolCategory(val titleRes: Int, val iconRes: Int) {
    DAILY(R.string.cat_daily, R.drawable.ic_cat_daily),
    MEDIA(R.string.cat_media, R.drawable.ic_cat_media),
    HARDWARE(R.string.cat_hardware, R.drawable.ic_cat_hardware),
    DEV(R.string.cat_dev, R.drawable.ic_cat_dev)
}

data class ToolDefinition(
    val id: String,
    val titleRes: Int,
    val descRes: Int,
    val category: ToolCategory,
    val iconRes: Int,
    val route: String,
    val requiredPermissions: List<String> = emptyList(),
    val supportsWidget: Boolean = false
)

// :core:data
interface ToolProvider {
    fun getToolDefinition(): ToolDefinition
    fun registerRoute(navGraphBuilder: NavGraphBuilder, navController: NavHostController)
}
```

## 五、状态管理、错误处理与权限模式
- **状态流**：`MVI / 简化 MVVM`。所有页面暴露 `StateFlow<UiState>`，涵盖 `Loading`、`Empty`、`Success`、`Error`、`PermissionRequired`。
- **错误与提示**：统一领域 `Result<T>` 封装，通过 `Channel<UiEffect>` 驱动 Material 3 `Snackbar` 浮层。
- **权限申请**：采用官方 `rememberLauncherForActivityResult(ActivityResultContracts.RequestMultiplePermissions())` 配合清晰的前提解释弹窗（Rationale Dialog），杜绝无解释直接索权。

## 六、关键技术风控与解决方案
1. **大图 OOM 防御**：采用 `BitmapFactory.Options.inJustDecodeBounds` 采样率计算与 Android 10+ `ImageDecoder`，后台 `Dispatchers.IO` 处理，绝不开辟冗余大对象。
2. **传感器缺失与漂移**：检查 `SensorManager.getDefaultSensor()`，无硬件时进入只读或模拟降级页面；地磁异常检测显示校准提示动画。
3. **音频与相机合规**：录音仅存内存瞬时缓冲区计算 RMS，不生成临时文件；相机仅用于条码解析，不上传任何帧数据。
4. **无广告与商店审核**：无动态代码下发，权限最小化申报，符合 Google Play / 国内各大主流渠道严苛审查。

## 七、首版 3 周开发交付计划
- **Week 1 (基座与基础工具)**: 模块拆解、Design System、DataStore、ToolRegistry、文本/时间戳/密码/进制转换。
- **Week 2 (多媒体与硬件工具)**: CameraX 扫码/ZXing、图片压缩、EXIF 清除、传感器指南针、分贝计。
- **Week 3 (倒计时、小组件与验收)**: Room 数据库、WorkManager、Glance 桌面小组件、空状态/无权限页面完善、性能 Profiling 与发布。
